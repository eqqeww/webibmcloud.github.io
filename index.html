เนื้อหา IBM Cloud Service

2.1Service (การบริการหลักๆ)รูปแบบบริการ as a Service ทั้ง 11 ประเภท 2.2Data Center Locationภูมิภาคและเมืองที่ตั้ง 2.3Pricing ModelLite, Pay-as-you-go และอื่นๆ 2.4Pro (ข้อดี) และ Con (ข้อเสีย)สรุปข้อดีและข้อเสีย 2.5Certification pathจากระดับเริ่มต้นถึงสูง
2.1

Service (การบริการหลักๆ)

บริการหลักของ IBM Cloud แบ่งตามรูปแบบ as a Service

2.1.1 IaaS

Infrastructure as a Service

เช่าโครงสร้างพื้นฐาน เช่น เครื่องเสมือนและเครื่องจริง

Virtual Servers for VPC · Bare Metal

2.1.2 CaaS

Container as a Service

รันและจัดการคอนเทนเนอร์ด้วย Kubernetes

IBM Cloud Kubernetes Service · Red Hat OpenShift

2.1.3 PaaS

Platform as a Service

แพลตฟอร์มพัฒนาและรันแอปโดยไม่ต้องดูแลเซิร์ฟเวอร์

Code Engine

2.1.4 FaaS

Function as a Service

รันโค้ดเป็นฟังก์ชันตามเหตุการณ์ จ่ายตามการใช้จริง

Code Engine Functions

2.1.5 DaaS

Database as a Service

ฐานข้อมูลที่ IBM ดูแลให้ ทั้ง SQL และ NoSQL

Db2 · Cloudant · Databases for PostgreSQL

2.1.6 Security & Identity

ความปลอดภัยและการยืนยันตัวตน

จัดการสิทธิ์ผู้ใช้ กุญแจเข้ารหัส และ compliance

IAM · Key Protect · Secrets Manager

2.1.7 Internet of Things

IoT (เทียบกับ Azure IoT)

Watson IoT Platform ถูกยกเลิกแล้ว ปัจจุบันเน้นชุด Maximo ส่วน Azure มี IoT Hub

Maximo Application Suite

2.1.8 STaaS

Storage as a Service

เก็บข้อมูลแบบอ็อบเจ็กต์ บล็อก และไฟล์

Cloud Object Storage · Block · File

2.1.9 Big Data & Analytics

วิเคราะห์ข้อมูลขนาดใหญ่

คลังข้อมูลและแพลตฟอร์มข้อมูลสำหรับงาน AI

watsonx.data · Analytics Engine

2.1.10 BCaaS

Blockchain as a Service

IBM Blockchain Platform ยุติการขายแล้ว จึงเป็นบริการเดิม

Hyperledger Fabric

2.1.11 LBaaS

Load Balancer as a Service

กระจายทราฟฟิกไปหลายเซิร์ฟเวอร์เพื่อความเสถียร

VPC Application / Network LB

แหล่งเปรียบเทียบ: comparecloud.in · ตรวจชื่อบริการล่าสุดที่ IBM Cloud Catalog

2.2

Data Center Location

ศูนย์ข้อมูลแบบ Multizone Region (MZR)

ภูมิภาคเมืองหลัก
อเมริกาเหนือDallas · Washington DC · Toronto · Montreal
อเมริกาใต้São Paulo
ยุโรปLondon · Frankfurt · Madrid
เอเชียแปซิฟิกTokyo · Osaka · Sydney

ประเทศไทยยังไม่มี Region ของ IBM Cloud · ตรวจรายการล่าสุดที่ IBM Cloud Locations

2.3

Pricing Model

รูปแบบการคิดราคาของ IBM Cloud

Lite

ใช้ฟรี

แพ็กเกจฟรีของบางบริการ มีข้อจำกัดปริมาณ เหมาะกับการทดลอง

Pay-as-you-go

จ่ายตามใช้จริง

คิดตามชั่วโมงหรือปริมาณ ไม่มีสัญญาผูกมัด

Subscription

สัญญารายเดือน/ปี

จ่ายล่วงหน้าเพื่อรับส่วนลดสำหรับงานที่ใช้ต่อเนื่อง

Reserved / Committed

จองล่วงหน้า

ผูกสัญญาระยะยาวเพื่อต้นทุนต่อหน่วยที่ต่ำลง

ประเมินค่าใช้จ่ายที่ Cost estimator · ราคาเปลี่ยนตามช่วงเวลา ควรระบุวันที่อ้างอิง

2.4

Pro (ข้อดี) และ Con (ข้อเสีย)

จุดแข็งและข้อจำกัดเมื่อเทียบกับ CSP รายใหญ่

ข้อดี

  • แข็งแรงด้าน Hybrid cloud และ Red Hat OpenShift
  • เน้นความปลอดภัยและ compliance เหมาะกับธนาคาร/ภาครัฐ
  • มีเครื่องมือ AI และข้อมูลผ่าน watsonx
  • มีตัวเลือก Bare Metal และการแยกทรัพยากรเฉพาะลูกค้า
  • มีแพ็กเกจ Lite ให้ทดลองฟรี

ข้อเสีย

  • ส่วนแบ่งตลาดน้อยกว่า AWS, Azure, Google Cloud
  • จำนวน Region น้อยกว่า และไม่มี Region ในไทย
  • แหล่งเรียนรู้ภาษาไทยมีจำกัด
  • บางบริการถูกยกเลิก/เปลี่ยนชื่อ ต้องตามข่าวสาร
  • ระบบนิเวศบริการสำเร็จรูปน้อยกว่าเจ้าใหญ่
2.5

Certification path

เส้นทางใบรับรองจากพื้นฐานสู่ผู้เชี่ยวชาญ

IBM Cloud Foundations

ระดับเริ่มต้น

แนวคิดคลาวด์และบริการพื้นฐาน (IBM SkillsBuild)

Cloud Developer / DevOps

ระดับกลาง

พัฒนาและปล่อยแอป, Kubernetes, CI/CD

Security Engineer

ระดับกลาง–สูง

ออกแบบและดูแลความปลอดภัยบน IBM Cloud

Solution Architect

ระดับสูง

ออกแบบสถาปัตยกรรมคลาวด์ระดับองค์กร

ชื่อใบรับรองเปลี่ยนตามปี ยืนยันที่ IBM Training & Certification
